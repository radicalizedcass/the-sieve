# Rows

Each row carries a dated cost. Costs state the failure, never the system, the person or the place — see [CONTRIBUTING.md](CONTRIBUTING.md).

---

## Delivery

### S-001 · delivered

| | |
|---|---|
| **confused with** | announced · described · promised |
| **the test** | Is the artifact — its bytes or its hash — in the same turn as the claim? |
| **say instead** | *"announced; artifact not on disk"* |
| **kind** | artifact |
| **the cost** | 2026-09-07 — three separate "here it is" claims across one session, none of which put a file anywhere the reader could open it. The failure was not dishonesty; each claim described a real intention. |

---

### S-002 · ran

| | |
|---|---|
| **confused with** | reported · scheduled · described |
| **the test** | Is there output produced *by the run itself* — an exit code, a log line, a receipt — rather than a description of the run? |
| **say instead** | *"reported; unrun"* |
| **kind** | artifact |
| **the cost** | 2026-09-10 — a survey reported as finished had reached two of six categories. The report was accurate about what it found and silent about what it never looked at. |

---

### S-003 · applies

| | |
|---|---|
| **confused with** | runs · works · is verified |
| **the test** | Did the changed file *execute*, not merely accept the change? |
| **say instead** | *"applies cleanly; execution untested"* |
| **kind** | artifact |
| **the cost** | 2026-09-11 — a patch was called verified on the strength of the change applying without conflict. Opened in a browser, the patched page rendered its two headline numbers as dashes: the edit had landed after a line that throws when an external script is unreachable. Applying was tested. Running never was. |

## Scope

### S-004 · complete

| | |
|---|---|
| **confused with** | answered · done · the part that was done |
| **the test** | Does the output name every part of the request, **including the parts not attempted, and why**? |
| **say instead** | *"partial — N of M; the rest not attempted because …"* |
| **kind** | witness |
| **the cost** | 2026-09-11 — a review declared a two-file package clean. One file had been checked. The word covered the package; the work covered half of it. |

### S-005 · continuable

| | |
|---|---|
| **confused with** | documented · recorded · handed off · well written |
| **the test** | Has someone who was **not** in the session resumed from the written record alone — and did the resumption produce an artifact? |
| **say instead** | *"recorded; continuation untested"* |
| **kind** | witness |
| **the cost** | 2026-09-11 — a body of records written over months explicitly so that a later reader could pick up the work. The test had never once been run. The first deliberate attempt succeeded, which is one data point, not a property. |

## Authority

### S-006 · sealed

| | |
|---|---|
| **confused with** | practice · current behaviour · written down somewhere |
| **the test** | Is it in a decided document, **in the place the work actually reads from** — or is it only what people do now? |
| **say instead** | *"practice, not sealed"* |
| **kind** | artifact |
| **the cost** | 2026-09-11 — a governing document was found to be 6,008 bytes shorter in the location the work read from than in the archive. The two newest sections — the ones written specifically as safeguards — were the size of the gap. |

## Evidence

### S-007 · a reading

| | |
|---|---|
| **confused with** | the event · the fact · the state |
| **the test** | Does a fresh read return it? A reading returns a reflection of the thing; the event returns the thing. |
| **say instead** | *"a reading, not the event"* |
| **kind** | witness |
| **the cost** | 2026-09-10 — a status view displayed a forecast as active. The forecast had closed sixty-eight days earlier. Nothing was wrong with the view; it was rendering a value nobody had re-read. |

---

### S-008 · the map

| | |
|---|---|
| **confused with** | the territory · the data it describes |
| **the test** | Are the catalogue's own summary figures **derived from the data**, or typed by hand? |
| **say instead** | *"a catalogue's claims are inferred until re-derived from what it describes"* |
| **kind** | field |
| **the cost** | 2026-06-22, found 2026-09-11 — a published catalogue's header announced one count while the array beneath it held ten more entries than that. Two further editions of the same catalogue, three weeks apart, each carried a third and fourth count. No single one was a typo; the pattern was a hand-typed number never derived. |
